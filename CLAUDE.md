# Project: Family Trivia Battle

A real-time multiplayer family trivia game. Stack: React + Vite + Firebase
(Realtime Database + Auth). Questions come from the local bank in
`src/data/questionBank.js` via `src/services/questionService.js`.

Deployed via **Netlify** (connected to this GitHub repo, branch
`claude/fervent-johnson-4sZ1O`). Firebase project: `family-trivia-f9231`.

## Working with this user (IMPORTANT)

The user is non-technical. When communicating:

- **Always put any text the user needs to copy/paste inside a fenced code
  block** (```), so the chat UI shows a one-click copy icon. This includes
  names, commands, URLs, config values — anything they must paste somewhere.
- Give clear, numbered, point-and-click steps. Avoid jargon; explain briefly.
- Prefer browser/GUI workflows over terminal commands.
